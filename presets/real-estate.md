# Preset: real estate / property tour

Use for house, apartment, rental, Airbnb, commercial space or construction walk-throughs.

## Structure
- **Opening (first 3 s):** the strongest shot - exterior hero shot, best view, or the most impressive room.
- **Route (walk it like a buyer):** exterior -> entry -> living -> dining/kitchen -> bedrooms (primary last) -> bathrooms -> laundry/garage -> backyard / balcony / view -> amenities / community -> closing exterior or wide shot.
- Short social cut (15-45 s): opening + the 5-8 best rooms + closing; skip laundry/garage unless special.

## Shots
- Normal shot 2-4 s; highlight shots (primary bedroom, kitchen, view, pool) 5-6 s; never under 1.5 s.
- Use one complete pan/tilt/glide inside its usable window; start and end on calm frames.
- Max 3 consecutive shots of the same room. Never two near-identical framings back to back.
- When there is a choice, keep camera moves flowing in one direction (pan_left -> pan_left).
- Prefer wide, level, bright shots; drop blurry, shaky, dark, cluttered or people-in-frame shots unless asked.

## Sound
Usually no useful on-site sound (wind, footsteps, HVAC). Default: silent output, ready for music.
If an agent talks on camera, keep their sentences whole (see talking-head preset for cut rules).

## Space labels for labels.json
exterior, entry, living, dining, kitchen, bedroom, primary_bedroom, bathroom, laundry, garage, office, stairs,
backyard, balcony, pool, view, amenity, community, detail, person, other

## Default lengths
Landscape (YouTube / website / MLS): 60-120 s, default 90 s. Portrait (Reels / TikTok / Shorts): 30-60 s, default 45 s.
